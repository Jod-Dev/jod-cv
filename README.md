## 🚀 Installation and Usage

### Prerequisites
```bash
Node.js 18+ 
npm or yarn
```

### Installation
```bash
# Clone the repository
git clone https://github.com/Jod-Dev/jod-cv.git

# Enter the directory
cd jod-cv

# Install dependencies
npm install

# Run in development
npm run dev

# Build for production
npm run build

# Preview build
npm run preview
```
