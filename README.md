## 🚀 Instalación y Uso

### Prerrequisitos
```bash
Node.js 18+ 
npm o yarn
```

### Instalación
```bash
# Clonar el repositorio
git clone https://github.com/Jod-Dev/jod-cv.git

# Entrar al directorio
cd jod-cv

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Construir para producción
npm run build

# Previsualizar build
npm run preview
```
